    Site Variables

    Rendered Output:

    • Site Title: My Info Just Under Glass
    • Site Description: MIJUG.NET serves the communities of Southeast Michigan, Ohio, and Florida with technology, sustainability, and community engagement resources. A platform by Kranson Enterprises for sharing knowledge and connecting communities.

    Liquid Syntax:

    - **Site Title**: {{ site.title }}
- **Site Description**: {{ site.description }}
- **Site URL**: {{ site.url }}{{ site.baseurl }}
- **Build Time**: {{ site.time | date: "%B %d, %Y at %I:%M %p" }}

    Rendered Output:

    Liquid Syntax:

    {% if page.title %}

    Case Statements

    Rendered Output:

    📄 This is a regular page

    Liquid Syntax:

    {% assign content_type = page.layout %}
{% case content_type %}
{% when 'post' %}
📝 This is a blog post
{% when 'page' %}
📄 This is a regular page
{% when 'documentation' %}
📚 This is documentation
{% else %}
📋 This is content of type: {{ content_type }}
{% endcase %}

    Best Practices Demonstrated

    1. Use unless for negative conditions
    2. Prefer assign over direct computation in loops
    3. Use default filter for undefined variables
    4. Use raw tags when displaying Liquid syntax
    5. Use capture for complex multi-line content
    6. Always check for existence before using site.data
